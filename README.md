# Java Assignment 2.3 – Library Management System

## Description
This Java project demonstrates a simple library management system using object-oriented programming.

## Completed Tasks

- **Task 1:** Library and Books Association – Completed
- **Task 2:** Book Borrowing System – Completed
- **Task 3:** Book Availability Check – Completed
- **Task 4:** Book Ratings and Reviews – Completed
- **Task 5:** Library Statistics – Completed
- **Task 6:** Library Users – Completed

## Java Classes

- `Book.java` – Stores book details, ratings, and reviews.
- `Library.java` – Manages books, borrowing, returns, availability, statistics, and users.
- `User.java` – Stores user information and borrowed books.
- `LibraryMain.java` – Tests the library management system.

## How to Run

1. Open the project in IntelliJ IDEA.
2. Open `LibraryMain.java`.
3. Run the `main()` method.
4. View the results in the console.

## Testing

All six tasks have been implemented and tested successfully.

The program runs without errors using Java 17.
